# Lahronda Little Book Event — welcome email

Subject: You're registered: Lahronda Little Book Event | November 14

In the Zapier Gmail Send Email action:
1. Map To to the registrant's email address.
2. Set Body Type to HTML.
3. Paste all of welcome-email-paste.txt into Body.
4. Choose the Foundry sending account and sender name.
5. Filter the Zap to event code LITT1126-1 and prevent duplicate sends using Welcome Email Sent.
6. Test with your own registration before enabling. Check that both images load in Gmail.

The HTML uses public raw GitHub image URLs. These become usable only after the repository and files are published. preview.html uses the included local images. The message needs no personalization tokens. The Add to Google Calendar button opens an editable event for November 14, 2026 at 4:00 p.m. America/New_York. The 6:00 p.m. end time is an estimate based on a two-hour duration because the actual end time was not supplied; the calendar description explicitly notes this.

This is the email content, not a configured or enabled Zap.
